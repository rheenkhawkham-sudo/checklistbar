# Daily Bar Check

ทำ check list สำหรับบาร์ รายวันและรายเดือน มีกล่องทำเครื่องหมาย อันไหนเสร็จแล้ว อันไหนยังไม่เสร็จ สามารถ เพิ่ม ลบ และแก้ไข task ทั้งหมดได้ มีช่อง submit เมื่อกด submit ให้ส่งข้อมูลทั้งหมดไปในอีเมล มีช่องให้ใส่ชื่ออีเมลด้วยและเมื่อกด submit ให้ส่งข้อมูลทั้งหมดไปในอีเมลจริงๆ rheen.khawkham@gmail.com ใช้ชื่ออีเมลนี้โดยอัตโนมัติเมื่อกด submit และเปลี่ยนเป็นภาษาอังกฤษทั้งหมด เพิ่มภาพเป็นวงกลมเปอร์เซ็นว่างานสำเร็จไปกี่เปอร์เซ็นแล้ว ใว้ด้านบนสุด ใส่ช่อง outlet แก้ไขได้ และ ให้ลงชื่อคนที่ทำ checklist นี้ด้วย ก่อนกด submit และสร้างเป็นแอพพลิเคชั่น หรือเว็บไซส์ สามารถให้ใครก็ได้เข้าไปทำ check list นี้ แค่มีชื่อเว็บไซต์หรือแอพพลิเคชั่น ที่ส่งให้
